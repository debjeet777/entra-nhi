# Contributing to EntraNHI

Thank you for your interest in EntraNHI.

The project is currently in its initial architecture and design phase. Contribution guidelines will evolve as the implementation and public interfaces stabilize.

## General requirements

Contributions should:

- remain within the documented project scope;
- preserve security and tenant-isolation boundaries;
- avoid introducing credentials, secrets, tenant data, or personal data;
- include appropriate tests for behavioral changes;
- preserve deterministic security-analysis behavior; and
- update relevant documentation when contracts or behavior change.

## Security

Never commit credentials, tokens, certificates, private keys, tenant exports, or other sensitive material.

Potential vulnerabilities should be reported according to [SECURITY.md](SECURITY.md), not through public issues.

## Development

Detailed build, testing, coding, and pull-request guidance will be added once the initial architecture and development baseline are established.
