# Security Policy

## Project status

EntraNHI is currently in early-stage development and should not yet be considered production-ready.

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting capability for this repository when available.

Do not include production credentials, access tokens, tenant data, personal data, or other sensitive information in vulnerability reports, issues, discussions, or example files.

## Security principles

EntraNHI is designed around:

- read-only assessment by default;
- least-privilege access;
- explicit authorization boundaries;
- deterministic security analysis;
- evidence-based findings;
- secure handling of authentication material; and
- no credentials or secrets committed to source control.

A detailed threat model and security architecture will be maintained as the project develops.
